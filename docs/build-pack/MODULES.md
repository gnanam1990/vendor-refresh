# Vendor Refresh · module index

These are dependency-ordered work units. Once a contract is agreed, UI, adapter and test contributors may proceed on fixtures matching that contract and integrate against its real implementation before acceptance.

1. [M01 · Vendor master and invoices](prompts/M01.md) — Build CSV preview, explicit column mapping, SIREN validation and tenant-scoped deduplication. Save raw permitted values alongside parsed observations.
2. [M02 · Freshness and conflict cases](prompts/M02.md) — Implement a versioned clock-based policy and stable trigger coalescing per accepted supplier revision.
3. [M03 · Registry adapter and terms](prompts/M03.md) — Define provider discovery, quoted amount, metadata, source timing and lawful field retention. Implement a real eligible source and record environment evidence.
4. [M04 · Delegated spending and recovery](prompts/M04.md) — Bind the selected listing, amount, currency and grant to an intent. Use transactional reservations plus outbox, receipt matching and reconciliation.
5. [M05 · Field differences and decisions](prompts/M05.md) — Produce field-level deltas with source originals, effective dates and comparison rules. Apply an accepted decision using optimistic concurrency.
6. [M06 · AP inbox and sensitive exceptions](prompts/M06.md) — Build accessible case list, decision screen, exception routing and redacted evidence preview.
7. [M07 · Close, export and pilot evidence](prompts/M07.md) — Build paginated accepted-change export, spend reconciliation and pilot report of paid checks, unresolved items and analyst time.
